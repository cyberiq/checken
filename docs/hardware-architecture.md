# اختيار العتاد وطريقة الربط والتوصيل

## 1. نظرة عامة

يعتمد هذا النظام على وحدة ESP32 كمركز معالجة وقياس، مع مستشعرات متخصصة للغازات والحرارة والرطوبة والأكسجين، بالإضافة إلى نظام إنذار محلي ومراقبة عن بعد.

## 2. المكونات المقترحة

### 2.1 ESP32
- الطراز: ESP32 أو ESP32-S3
- السبب:
  - Wi-Fi وBluetooth
  - عدد منافذ GPIO مناسبة
  - دعم UART وI2C وADC
  - مناسب للبيئات الزراعية والصناعية

### 2.2 مستشعر الأمونيا NH3
- الموصى به: Winsen ZE03-NH3
- المعايير:
  - قراءات خطية
  - دقة مناسبة
  - خرج UART مباشر
  - مناسب للعمر الافتراضي في البيئات ذات الرطوبة العالية

### 2.3 مستشعر الحرارة والرطوبة
- الموصى به: SHT31
- ميزاته:
  - دقة عالية
  - استهلاك منخفض
  - مناسب للبيئة الزراعية
- التثبيت:
  - إرفاق غطاء مسامي من البلاسيتيك أو الفلتر المسموح به
  - وضعه بعيداً عن مصادر الحرارة المباشرة أو الرياح القوية

### 2.4 مستشعر الأكسجين
- الموصى به: Winsen ZE25-O2 أو DFRobot Electrochemical O2
- الفائدة:
  - يقيس نسبة الأكسجين داخل الحظيرة بدقة
  - يساعد في اتخاذ قرارات التهوية

### 2.5 شاشة العرض
- LCD 2004 عبر I2C أو OLED 0.96
- الاستخدام:
  - عرض القيم فوراً داخل المزرعة
  - مراقبة سريعة دون الهاتف

### 2.6 الإنذار المحلي
- Active Buzzer
- Relay لتحريك مروحة الطوارئ أو نظام شفط الهواء
- عند تجاوز الحد: يتم تنشيط البازر + تشغيل المراوح

### 2.7 alimentation
- مصدر 12V/2A
- منظم 5V باستخدام LM2596
- مزايا:
  - استقرار الجهد
  - حماية من تقلبات الطاقة الناتجة عن المولدات أو الألواح الشمسية

### 2.8 الحماية الفيزيائية
- صندوق بلاستيكي IP65
- فتحات تهوية مناسبة
- حماية من الغبار، الرطوبة، ورذاذ التعقيم

## 3. مخطط التوصيل المقترح

### 3.1 ESP32 إلى المستشعرات

| المكون | التوصيل المقترح |
|---|---|
| SHT31 | SDA -> GPIO21, SCL -> GPIO22 |
| ZE03-NH3 | TX -> GPIO17, RX -> GPIO16 |
| ZE25-O2 | TX/RX -> UART2 أو ADC حسب الطراز |
| LCD 2004 | SDA -> GPIO21, SCL -> GPIO22 |
| Buzzer | GPIO25 عبر ترانزستور NPN |
| Relay fan | GPIO26 عبر ترانزستور/مؤقت |
| 5V rail | ESP32 + مستشعرات + شاشة |

### 3.2 ملاحظات التوصيل
- يجب استخدام مقاومات سحب مناسبة إذا كان هناك خرج Open-Drain.
- يفضّل استخدام أرضية مشتركة (GND) لجميع الوحدات.
- إذا كان مستشعر الغاز يحتاج 5V أو 3.3V، مراجعة datasheet لكل موديل.
- يوصى بتركيب فاصل/مرشح على خرج الطاقة قبل ESP32.

---

## 4. توضيح هندسي للتثبيت

- توضع شاشة LCD في نقطة رؤية سهلة داخل غرفة التحكم أو بجوار الباب.
- توضع مستشعرات الغاز والحرارة في منطقة التهوية الأعلى وليس قرب الأرض مباشرة.
- يترك مجال كافٍ حول الحساسات لتجنب تراكم الروائح أو الريش.
- يوضع الصندوق الحافظ في مكان جاف ومحدود من الحرارة المباشرة.

---

## 5. ملاحظات فنية مهمة

- لا توصل مستشعرات الغاز مباشرة إلى ESP32 دون فحص الجهد المناسب.
- إذا استخدمت MQ-137، فاحرص على تسخينه وتسجيل المعايرة في البداية.
- يفضّل ZE03 over MQ-137 لسهولة القراءة والقراءات الخطية.
- استخدم كابلات مزدوجة مغلفة أو كابلات مقاومة للضغط والحرارة عند تمريرها داخل المزرعة.

---

## 6. الخلاصة

اختيار ESP32 + ZE03-NH3 + SHT31 + ZE25-O2 يحقق نظاماً متوازناً بين الدقة والتكلفة وسهولة التنفيذ. هذا التكوين مناسب جداً للمزارع الصغيرة والمتوسطة ويمنحها مراقبة دقيقة وفعالية عالية في الإنذار المبكر.
